# Session continuity and documentation

Use [AGENTS.md](../../../AGENTS.md), [status](../../../docs/STATUS.md), [tasks](../../../tasks.md) and the task-relevant owner. Read actual source and exact-commit evidence before reconciling a prior summary. Archives are dated evidence, not current instructions.

Preserve task/feature/source IDs and distinguish implemented, reproduced, tested, compared and accepted. Keep one product queue and the existing parity ledgers. Update the current resume note rather than append competing summaries or ask the owner to reconstruct prior context.

A handoff identifies the exact commit, changed behavior, actual checks, evidence paths, failure/not-run boundaries and next concrete action. Do not mark a service or source gate complete because docs were rewritten. Run the lightweight docs/skill checks for documentation-only changes and preserve immutable upstream files/licenses.
